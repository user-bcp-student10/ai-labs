# Hallazgos

Seguimiento de hallazgos de auth. Los estados reflejan únicamente los cambios y verificaciones registrados; la aprobación humana consta en `PLAN.md`. `docs/ENDPOINTS.md` no existe, por lo que se registra abajo el contrato observado en el código.

## Contrato observado de auth

`POST /auth/login` recibe un JSON con `username`, `password` y admite `client`. El código responde 400 si falta el request, username o password; 401 si no encuentra credenciales; y 200 con `token`, `expiresIn`, datos de usuario y `debug` si autentica. El error de autenticación incluye el username enviado. Evidencia: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:22-23,26-37,39-49` y `auth/src/main/java/com/bcp/workshop/auth/LoginRequest.java:3-6`.
